GitHub 令牌（帖子自动存进本网站所在的仓库，只需填一次令牌）

点「发布」后，帖子会自动提交到本网站所在的 GitHub 仓库（不用填仓库名，网页自动识别），等 1～2 分钟 GitHub Pages 更新后，所有人刷新网页就能看到。
令牌只需要配置一次，只保存在你自己的浏览器里。
令牌获取方法：登录 GitHub → 右上角头像 → Settings → 最左边最下面 Developer settings → Personal access tokens → Tokens (classic) → Generate new token (classic) → 勾选 repo → Generate token → 复制后粘贴到上面。
